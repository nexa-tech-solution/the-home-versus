# Google Search Console Checklist

Use this checklist to improve SEO and GEO for `the-home-versus`.

## Weekly

- Check `Performance > Search results`
- Sort by `Pages` and identify pages with high impressions but low CTR
- Rewrite titles for pages with weak CTR
- Rewrite meta descriptions for pages with good impressions but low clicks
- Look at `Queries` and add missing intent terms to the page copy
- Inspect the top 5 pages with the most impressions
- Request indexing for any newly published product or comparison page

## Monthly

- Check `Pages` for:
  - `Crawled - currently not indexed`
  - `Discovered - currently not indexed`
  - `Duplicate without user-selected canonical`
  - `Not found (404)`
  - `Alternate page with proper canonical tag`
- Review `Experience > Core Web Vitals`
- Review `Enhancements` for:
  - Product rich results
  - Breadcrumb rich results
  - FAQ rich results
  - Article rich results
- Update pages that are ranking on page 2
- Add internal links from strong pages to weak pages

## After Publishing a New Page

- Inspect the URL in Search Console
- Confirm the canonical is correct
- Confirm the page is indexable
- Make sure the title includes:
  - product name
  - `review` or `vs`
  - the main buyer intent
- Make sure the intro clearly answers the search query
- Make sure the page has at least one FAQ if the topic supports it
- Make sure the page has schema that matches the content type

## For Product Pages

- Use a title like:
  - `Product Name Review`
  - `Product Name: Best For X`
- Include the main use case in the intro
- Add pros and cons
- Add FAQ questions based on likely search queries
- Add internal links to related comparisons
- Make sure the Product schema includes:
  - name
  - image
  - rating
  - review count
  - offers

## For Comparison Pages

- Use a title like:
  - `A vs B: Which Is Better for X?`
- Put the key decision in the first paragraph
- Include clear headings for:
  - difference in use case
  - which one wins for each job
  - safety or surface risks
  - final recommendation
- Add FAQ questions that sound like real searches
- Link both product pages in the verdict
- Make sure comparison schema includes both products

## GEO Improvements

- Write short answers near the top of the page
- Use direct language that answers `which is better`, `is it worth it`, and `best for`
- Keep product names consistent across title, heading, schema, and body copy
- Prefer specific nouns over vague marketing language
- Add FAQ answers that are complete in one or two sentences
- Use clear comparison logic:
  - what it is
  - when to buy it
  - when not to buy it
  - who it is for

## Fast Wins

- Pages with many impressions and low CTR:
  - rewrite title
  - rewrite meta description
  - make the first paragraph more direct
- Pages indexed but not getting impressions:
  - add internal links
  - strengthen headings
  - expand FAQs
  - add more specific keywords
- Pages ranking on page 2:
  - improve intro
  - add missing subtopics
  - add comparison or use-case sections

## Simple Rule Set

- One page = one main search intent
- One title = one clear promise
- One intro = one direct answer
- One FAQ = one real user question
- One comparison = one clear winner or conditional winner
